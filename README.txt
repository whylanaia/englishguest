ENGLISHQUEST — ПУБЛИКАЦИЯ БЕСПЛАТНОГО САЙТА

Что это
- Бесплатная статическая учебная платформа на HTML/CSS/JavaScript.
- 12 стартовых уроков, тесты, словарь, разговорные фразы, озвучивание браузером, ежедневный чек-лист, XP и достижения.
- Добавлены PWA-файлы для установки на экран телефона и кэширования оболочки сайта.
- Не нужны платный сервер, база данных или API-ключ.

КАК ПОЛУЧИТЬ ПОСТОЯННУЮ ССЫЛКУ ЧЕРЕЗ GITHUB PAGES
1. На компьютере открой https://github.com/ и создай бесплатный аккаунт или войди в существующий.
2. Нажми + вверху справа → New repository.
3. Назови репозиторий englishquest, выбери Public и нажми Create repository.
4. В репозитории нажми Add file → Upload files.
5. Распакуй этот архив на компьютере. Перетащи СОДЕРЖИМОЕ папки EnglishQuest (index.html, manifest.webmanifest, icon.svg, sw.js, README.txt) на страницу загрузки GitHub. Не загружай ZIP вместо файлов.
6. Нажми Commit changes.
7. Открой Settings → Pages.
8. В разделе Build and deployment выбери Deploy from a branch.
9. Выбери Branch: main и Folder: /(root), затем Save.
10. Подожди пару минут и обнови Settings → Pages. GitHub покажет адрес сайта вида https://ТВОЙ-ЛОГИН.github.io/englishquest/ . Это и есть твоя постоянная ссылка.

КАК ОТКРЫВАТЬ НА ТЕЛЕФОНЕ
1. Открой опубликованную ссылку в Safari на iPhone.
2. Нажми «Поделиться».
3. Выбери «На экран Домой» → «Добавить».
На компьютере просто добавь ссылку в закладки. На Android в поддерживаемом браузере может появиться команда установки приложения.

ВАЖНО О ПРОГРЕССЕ
На текущем этапе прогресс сохраняется локально в браузере и не синхронизируется между телефоном и компьютером. Пока не создана облачная учётная запись. Чтобы перенести прогресс, используй «Скачать резервную копию» на одном устройстве и «Восстановить копию» на другом.

БЕСПЛАТНОСТЬ И ПУБЛИКАЦИЯ
GitHub Pages подходит для такого статического сайта и предоставляет публичный HTTPS-адрес бесплатно в рамках своих условий. Не публикуй в репозитории пароли, личные данные или секретные ключи.

ЕСЛИ САЙТ НЕ ОТКРЫВАЕТСЯ
- Проверь, что index.html лежит в корне репозитория, а не внутри дополнительной папки.
- В Settings → Pages проверь ветку main и папку /(root).
- Подожди 2–5 минут после публикации и обнови страницу.
- Если обновления не видны, попробуй обновить страницу без кэша или открыть её в приватной вкладке.
